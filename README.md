# Dra. Larissa Guilherme - Site Institucional

Site institucional premium e moderno para a clínica estética da Dra. Larissa Guilherme, Biomédica Esteta especializada em tratamentos estéticos avançados.

## 🌟 Sobre

Site desenvolvido com HTML5, CSS3 e JavaScript puro (sem frameworks), focado em elegância, sofisticação e experiência do usuário premium.

## 📋 Características

- ✨ Design premium e sofisticado
- 📱 Totalmente responsivo (mobile-first)
- 🎨 Paleta de cores elegante (dourado, bege, areia, branco)
- ⚡ Performance otimizada
- ♿ Acessibilidade implementada
- 🔍 SEO básico configurado
- 💬 Integração com WhatsApp
- 📸 Galeria de imagens com lightbox
- 🗺️ Mapa do Google Maps integrado
- 📱 Link para Instagram

## 🚀 Como Usar

1. Clone o repositório
2. Adicione as imagens na pasta `images/` seguindo os nomes especificados
3. Abra o arquivo `index.html` em um navegador
4. Para publicar, faça upload dos arquivos para seu servidor web

## 📝 Personalização

### Cores
As cores podem ser alteradas no arquivo `style.css` nas variáveis CSS:
- `--color-primary`: Dourado principal
- `--color-secondary`: Bege secundário
- `--color-beige`: Bege claro
- `--color-sand`: Areia

### Conteúdo
Todo o conteúdo pode ser editado diretamente no arquivo `index.html`.

### Funcionalidades
Funcionalidades JavaScript estão no arquivo `script.js` e incluem:
- Menu mobile responsivo
- Scroll suave entre seções
- Animações ao scroll
- Lightbox para galeria
- Link ativo na navegação
